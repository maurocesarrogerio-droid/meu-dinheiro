Dados e segurança

Cuide das informações do seu controle financeiro.

Seus registros ficam no armazenamento local do navegador. Eles não são enviados para um banco ou instituição financeira.

Importante: se limpar os dados do navegador, trocar de aparelho ou usar outro navegador, os registros poderão não estar disponíveis. Exporte backups regularmente. Não registre senhas, números completos de cartões ou dados bancários sigilosos.

O que este aplicativo faz

Controle manual de finanças pessoais.

✓ Registra entradas e despesas
✓ Calcula saldo acumulado e resumo mensal
✓ Filtra e pesquisa movimentações
✓ Acompanha orçamento e meta de economia
✓ Permite exportar e restaurar backup
— Não acessa contas bancárias automaticamente
— Não sincroniza dados entre aparelhos
